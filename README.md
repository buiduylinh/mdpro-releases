# MD Pro: bản cài đặt

Phần mềm đo âm thanh MD Pro cho Windows.

**Tải bản mới nhất:** [Releases](https://github.com/buiduylinh/mdpro-releases/releases/latest). Ở đó tải file `MDPro-Setup-<phiên bản>.exe` rồi chạy.

- **Cảnh báo SmartScreen** ("Windows protected your PC"): bấm "More info" rồi chọn "Run anyway".
- **Lần đầu mở MD Pro:** app hiện mã máy. Gửi mã đó cho nhà cung cấp để nhận key kích hoạt.
- **Cập nhật:** MD Pro tự kiểm tra bản mới ở đây và hỏi trước khi cài.

Repo này chỉ chứa bản cài đặt. Các file `update.json` và `update.json.sig` dùng cho chức năng tự cập nhật; bạn không cần tải chúng.
